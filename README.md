# Buenos Aires em Família — Julho 2027

Painel estático (HTML puro, sem build) com o planejamento da viagem: passagens, bairros seguros, orçamento e etapas.

## Publicar no GitHub

git init
git add index.html README.md
git commit -m "dashboard viagem argentina"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/SEU-REPO.git
git push -u origin main

## Deploy no Vercel

1. Acesse vercel.com → Add New Project
2. Importe o reposi    type:'ditHub que você acabou de criar
3. Framework preset: escolha Other (é HTML estático, não precisa de build command)
4. Clique em Deploy
